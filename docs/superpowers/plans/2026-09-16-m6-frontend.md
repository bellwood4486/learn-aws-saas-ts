# M6: フロントエンド（ローカルのみ） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** バックエンドに `GET /api/items`（一覧）を追加したうえで、`apps/web` を Vite + React + TypeScript で新規実装する。Cognito への直接ログイン（`USER_PASSWORD_AUTH`）、item一覧の表示、item作成フォームを実装し、Vite dev server の proxy でローカル起動の `apps/api` に繋いで `just dev-all` からブラウザで一連の操作ができることを確認する。CloudFront・ALB・ECS は使わない。

**Architecture:** バックエンドは既存の `createItem`/`getItem`（`packages/core/src/items.ts`）と同じ合成パターンで `listItems` を追加し、`apps/api` に `GET /api/items` ルートを1本追加する（既存2ルートと同じ `preHandler: app.authenticate` で認証必須）。フロントエンドは `apps/web` を新規パッケージとして作り、ルーティングライブラリは使わず単一の `App.tsx` が認証状態（`useAuth` の `accessToken` の有無）で `LoginForm` と 一覧＋作成フォーム を出し分ける。Cognitoへのログインは `@aws-sdk/client-cognito-identity-provider` の `InitiateAuthCommand` を直接呼ぶ薄いラッパー（`auth/cognito.ts`）で行い、access tokenはReact stateのみで保持する（リロードで消える。refresh tokenは扱わない）。APIコールは `api/client.ts` の fetch ラッパーが `Authorization: Bearer <token>` を付与し、401なら`useAuth`の`logout`を呼ぶ。データ取得・更新は TanStack Query（`useQuery`/`useMutation`）を使う。

**Tech Stack:** Vite 7 + React 19 + TypeScript 5.9 / `@tanstack/react-query` 5 / `@aws-sdk/client-cognito-identity-provider` 3 / Vitest + `@testing-library/react` + `@testing-library/jest-dom` + `@testing-library/user-event`（jsdom環境） / Fastify 5（既存） + Drizzle ORM（既存）

**Spec:** `docs/superpowers/specs/2026-08-15-aws-saas-backend-design.md`（「M6: フロントエンド」節、「バックエンド追加スコープ」節、「apps/web の構成」節、「設計判断」節、「検証方法」節のM6行）

## Global Constraints

- TypeScriptはNode 24の型除去で動く範囲に収める（`apps/api`/`packages/core`側。`enum`・デコレータ・パラメータプロパティ不可、相対importに`.ts`拡張子必須）
- `apps/web` は Vite/esbuild がトランスパイルするため上記の型除去制約を受けない。ただし相対importには他パッケージと同じく拡張子（`.ts`/`.tsx`）を書く（プロジェクト全体のスタイルに合わせる）
- Biomeのフォーマット規約に従う（シングルクォート、セミコロンあり、デフォルトエクスポートは使わない。既存コードは全て named export）
- ユニットテストは実AWS・実Cognitoに一切繋がない（プロジェクト方針）。バックエンドは`aws-sdk-client-mock`、フロントエンドはCognito呼び出しと`fetch`をモックする
- `apps/web` の認証はCognitoへの直接ログイン（`USER_PASSWORD_AUTH`）のみ。Hosted UI / OAuthコールバックは実装しない
- access tokenはReact stateのみで保持する。sessionStorage/localStorageは使わない
- ページネーション・一覧の絞り込みは実装しない（対象外。データ量が少ない学習用途のため）
- `apps/web/.env.local`（Vite環境変数。値: `VITE_COGNITO_CLIENT_ID` / `VITE_AWS_REGION`）はcommitしない。`.env.template`にキーのみ残す
- `infra/network` / `infra/data` への`apply`/`destroy`は課金・破壊的操作なので、実行前に必ずユーザーの明示的な承認を得る（Task 10）

```typescript
export interface ListItemsDeps {
  db: Database;
  itemsTableName: string;
}

/**
 * RDSの全行（作成日時の降順）にDynamoDBのstatusを合成して返す。
 * 行ごとにDynamoDBへ1回getする（N+1）が、学習用途でデータ量が少ないため許容し、
 * getItemとの実装の一貫性を優先する。
 */
export async function listItems(deps: ListItemsDeps): Promise<Item[]> {
  const rows = await deps.db.select().from(items).orderBy(desc(items.createdAt));

  const result: Item[] = [];
  for (const row of rows) {
    const record = await getStatusRecord(deps.itemsTableName, { id: row.id });
    if (record === undefined) {
      throw new Error(`item status record not found in DynamoDB for id: ${row.id}`);
    }
    result.push(composeItem(row, parseItemStatus(record.status)));
  }
  return result;
}
```

import {
  CognitoIdentityProviderClient,
  InitiateAuthCommand,
} from '@aws-sdk/client-cognito-identity-provider';

export interface LoginParams {
  region: string;
  clientId: string;
  username: string;
  password: string;
}

export interface LoginResult {
  accessToken: string;
}

/**
 * Cognitoに USER_PASSWORD_AUTH で直接ログインする。
 * InitiateAuthCommand は ClientId のみを要求し UserPoolId は使わない。
 */
export async function login(params: LoginParams): Promise<LoginResult> {
  const client = new CognitoIdentityProviderClient({ region: params.region });
  const result = await client.send(
    new InitiateAuthCommand({
      AuthFlow: 'USER_PASSWORD_AUTH',
      ClientId: params.clientId,
      AuthParameters: {
        USERNAME: params.username,
        PASSWORD: params.password,
      },
    }),
  );

  const accessToken = result.AuthenticationResult?.AccessToken;
  if (accessToken === undefined) {
    throw new Error('Cognito did not return an access token');
  }

  return { accessToken };
}

import { useCallback, useState } from 'react';
import { login as cognitoLogin } from './cognito.ts';

export interface AuthConfig {
  region: string;
  clientId: string;
}

export interface UseAuthResult {
  accessToken: string | null;
  error: string | null;
  isLoggingIn: boolean;
  login: (username: string, password: string) => Promise<void>;
  logout: () => void;
}

/** Cognitoへの直接ログインの状態をReact stateだけで保持する（sessionStorage等は使わない）。 */
export function useAuth(config: AuthConfig): UseAuthResult {
  const [accessToken, setAccessToken] = useState<string | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [isLoggingIn, setIsLoggingIn] = useState(false);

  const login = useCallback(
    async (username: string, password: string) => {
      setIsLoggingIn(true);
      setError(null);
      try {
        const result = await cognitoLogin({ ...config, username, password });
        setAccessToken(result.accessToken);
      } catch (err) {
        setError(err instanceof Error ? err.message : 'ログインに失敗しました');
      } finally {
        setIsLoggingIn(false);
      }
    },
    [config],
  );

  const logout = useCallback(() => {
    setAccessToken(null);
  }, []);

  return { accessToken, error, isLoggingIn, login, logout };
}

import type { CreateItemBody, Item } from '@repo/contracts';

export class UnauthorizedError extends Error {}

export interface ApiClientDeps {
  getAccessToken: () => string | null;
  onUnauthorized: () => void;
}

async function request<T>(deps: ApiClientDeps, path: string, init: RequestInit = {}): Promise<T> {
  const token = deps.getAccessToken();
  const headers = new Headers(init.headers);
  headers.set('Content-Type', 'application/json');
  if (token !== null) {
    headers.set('Authorization', `Bearer ${token}`);
  }

  const res = await fetch(path, { ...init, headers });

  if (res.status === 401) {
    deps.onUnauthorized();
    throw new UnauthorizedError('unauthorized');
  }
  if (!res.ok) {
    throw new Error(`request failed: ${res.status}`);
  }
  return (await res.json()) as T;
}

/** `/api` 配下のFastify APIを呼ぶクライアント。トークン取得と401時の挙動は依存として注入する。 */
export function createApiClient(deps: ApiClientDeps) {
  return {
    listItems: () => request<Item[]>(deps, '/api/items'),
    createItem: (input: CreateItemBody) =>
      request<Item>(deps, '/api/items', { method: 'POST', body: JSON.stringify(input) }),
  };
}

`apps/web/src/App.tsx` を以下で置き換える:

```typescript
import { createApiClient } from './api/client.ts';
import { useAuth } from './auth/useAuth.ts';
import { CreateItemForm } from './components/CreateItemForm.tsx';
import { ItemList } from './components/ItemList.tsx';
import { LoginForm } from './components/LoginForm.tsx';

const authConfig = {
  region: import.meta.env.VITE_AWS_REGION,
  clientId: import.meta.env.VITE_COGNITO_CLIENT_ID,
};

export function App() {
  const auth = useAuth(authConfig);

  if (auth.accessToken === null) {
    return <LoginForm onSubmit={auth.login} error={auth.error} isSubmitting={auth.isLoggingIn} />;
  }

  const client = createApiClient({
    getAccessToken: () => auth.accessToken,
    onUnauthorized: auth.logout,
  });

  return (
    <>
      <h1>Items</h1>
      <button type="button" onClick={auth.logout}>
        ログアウト
      </button>
      <CreateItemForm createItem={client.createItem} />
      <ItemList listItems={client.listItems} />
    </>
  );
}
```

const dbSecret = parseDbSecret(await getSecretValue(dbSecretArn));

  buildConnectionString(dbSecret, {
