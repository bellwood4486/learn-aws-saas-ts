# M5: Cognito（api の JWT 検証） Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `infra/platform/` に Cognito User Pool / App Client を追加し、`apps/api` に JWT 検証プラグインを実装して `POST /api/items` / `GET /api/items/:id` を認証必須にする。ALB の DNS 名に対して、JWT なしで 401、`aws cognito-idp admin-initiate-auth` で取得した Cognito 発行の JWT ありで 201 が返ることを確認する。

**Architecture:** ALB の `authenticate-cognito` リスナーアクションは HTTPS リスナー必須で今は使えないため（M7 で edge 層に ACM/HTTPS が来るまで待てない）、`apps/api` 側で JWT を検証する。`apps/api/src/plugins/auth.ts` を `fastify-plugin` でラップして `authenticate`（preHandler）を decorate し、実際の検証ロジック（`verifyToken`）は依存として注入する（テストでは AWS に繋がずフェイク関数を渡す）。本番の `verifyToken` は `main.ts` が `aws-jwt-verify` の `CognitoJwtVerifier` で組み立てる。Terraform は Cognito User Pool / App Client を常時起動の `infra/platform/` に追加し、`infra/app/` の api タスク定義に User Pool ID / App Client ID を環境変数として配線する。

**Tech Stack:** Fastify 5 + `fastify-plugin` 6 / `aws-jwt-verify` 5（JWKS 検証・キャッシュ込み） / Terraform 1.15.8, AWS provider `~> 6.0`（`aws_cognito_user_pool` / `aws_cognito_user_pool_client`） / Vitest（AWS に繋がずフェイクの `verifyToken` でテスト）

**Spec:** `docs/superpowers/specs/2026-08-15-aws-saas-backend-design.md`（「M5: Cognito」節、「Terraform のレイヤー分割」節の `infra/platform/` 行、「`apps/api`」節の `plugins/auth.ts` 記載、「検証方法」節の M5 行）

## Global Constraints

- Terraformリソース名はsnake_case・単数形、リソースタイプ名を名前に繰り返さない。用途がわかる名前を付ける（`this`/`main`は使わない）
- providerの`default_tags`で`Project`/`ManagedBy`/`Layer`を全リソースに付与する（`infra/platform/`は`Layer = "platform"`のまま。M5では新規層を作らない）
- **outputsに秘匿値を出さない。** Cognitoのoutputsに出すのはUser Pool ID / App Client IDのみ（どちらも秘匿値ではない）
- 層間の値は `terraform_remote_state` で読む。tfstateバケット名は `"${var.project_name}-tfstate-${data.aws_caller_identity.current.account_id}"` で組み立てる
- TypeScriptはNode 24の型除去で動く範囲に収める（`enum`・デコレータ・パラメータプロパティ不可、相対importに`.ts`拡張子必須）
- Biomeのフォーマット規約に従う（シングルクォート、セミコロンあり、デフォルトエクスポートは使わない。既存コードは全て named export）
- ユニットテストは実AWS・実Cognitoに一切繋がない（プロジェクト方針）。JWT検証は`verifyToken`という関数を依存として注入し、テストではフェイク関数に差し替える。実際の`aws-jwt-verify`はmain.tsでのみ組み立てる
- TFLintは`just tf-lint`で回す
- **`infra/platform`は常時起動層。実AWSへの`apply`は新規課金リソース（Cognito User Pool。無料枠内だが実リソース作成）を作るため、実行前に必ずユーザーの明示的な承認を得る（Task 3）。`network`/`data`/`app`への`apply`/`destroy`も同様に課金・破壊的操作なので承認を得る（Task 5, 6）**

`apps/api/src/plugins/auth.ts` を作成する:

```typescript
import fp from 'fastify-plugin';
import type { FastifyInstance, FastifyReply, FastifyRequest } from 'fastify';

export type VerifyToken = (token: string) => Promise<unknown>;

export interface AuthPluginOptions {
  verifyToken: VerifyToken;
}

declare module 'fastify' {
  interface FastifyInstance {
    authenticate(request: FastifyRequest, reply: FastifyReply): Promise<void>;
  }
}

const BEARER_PREFIX = 'Bearer ';

async function authPluginImpl(app: FastifyInstance, opts: AuthPluginOptions): Promise<void> {
  app.decorate('authenticate', async (request: FastifyRequest, reply: FastifyReply) => {
    const header = request.headers.authorization;
    if (header === undefined || !header.startsWith(BEARER_PREFIX)) {
      reply.code(401).send({ message: 'missing bearer token' });
      return;
    }

    const token = header.slice(BEARER_PREFIX.length);
    try {
      await opts.verifyToken(token);
    } catch {
      reply.code(401).send({ message: 'invalid token' });
    }
  });
}

/**
 * CognitoのJWTを検証するpreHandlerを`authenticate`としてdecorateする。
 * 検証方法自体は`verifyToken`に委譲する（本番の実装はmain.tsが`aws-jwt-verify`で組み立てる。
 * ユニットテストではAWSに繋がずフェイク関数を渡す）。
 */
export const authPlugin = fp(authPluginImpl);
```

```typescript
import Fastify, { type FastifyInstance } from 'fastify';
import { authPlugin, type VerifyToken } from './plugins/auth.ts';
import { healthRoutes } from './routes/health.ts';
import { itemRoutes, type ItemRoutesOptions } from './routes/items.ts';

export interface BuildServerDeps extends ItemRoutesOptions {
  verifyToken: VerifyToken;
}

/**
 * Fastify インスタンスの組み立てだけを行い、listen はしない。
 * テストは `app.inject()` でこの関数の戻り値を直接叩けるようにするため main.ts と分離している。
 */
export async function buildServer(deps: BuildServerDeps): Promise<FastifyInstance> {
  const app = Fastify({ logger: true });

  await app.register(healthRoutes);
  await app.register(authPlugin, { verifyToken: deps.verifyToken });
  await app.register(itemRoutes, deps);

  return app;
}
```

```typescript
import type { TypeBoxTypeProvider } from '@fastify/type-provider-typebox';
import { CreateItemBody, Item, ItemParams } from '@repo/contracts';
import type { Db } from '@repo/core';
import { createItem, getItem } from '@repo/core';
import type { FastifyInstance } from 'fastify';

export interface ItemRoutesOptions {
  db: Db['db'];
  itemsTableName: string;
  itemsQueueUrl: string;
}

/**
 * items の作成・参照。DBとAWSリソースへのアクセスは @repo/core の items ドメイン関数に委譲する。
 * `app.authenticate`（plugins/auth.ts。server.ts が先に登録する）を両ルートの preHandler にし、認証必須にする。
 */
export async function itemRoutes(app: FastifyInstance, opts: ItemRoutesOptions): Promise<void> {
  const server = app.withTypeProvider<TypeBoxTypeProvider>();

  server.post(
    '/api/items',
    { preHandler: app.authenticate, schema: { body: CreateItemBody, response: { 201: Item } } },
    async (request, reply) => {
      const item = await createItem(
        { db: opts.db, itemsTableName: opts.itemsTableName, itemsQueueUrl: opts.itemsQueueUrl },
        request.body,
      );
      reply.code(201);
      return item;
    },
  );

  server.get(
    '/api/items/:id',
    { preHandler: app.authenticate, schema: { params: ItemParams } },
    async (request, reply) => {
      const item = await getItem(
        { db: opts.db, itemsTableName: opts.itemsTableName },
        request.params.id,
      );
      if (item === undefined) {
        reply.code(404);
        return { message: 'item not found' };
      }
      return item;
    },
  );
}
```

```typescript
import { buildConnectionString, createDb, getSecretValue, parseDbSecret } from '@repo/core';
import { CognitoJwtVerifier } from 'aws-jwt-verify';
import { buildServer } from './server.ts';

function requireEnv(name: string): string {
  const value = process.env[name];
  if (value === undefined || value === '') {
    throw new Error(`${name} is not set`);
  }
  return value;
}

const dbSecretArn = requireEnv('DB_SECRET_ARN');
const itemsTableName = requireEnv('ITEMS_TABLE_NAME');
const itemsQueueUrl = requireEnv('ITEMS_QUEUE_URL');
const cognitoUserPoolId = requireEnv('COGNITO_USER_POOL_ID');
const cognitoClientId = requireEnv('COGNITO_CLIENT_ID');

const dbSecret = parseDbSecret(await getSecretValue(dbSecretArn));
const { db } = createDb(buildConnectionString(dbSecret));

const verifier = CognitoJwtVerifier.create({
  userPoolId: cognitoUserPoolId,
  tokenUse: 'access',
  clientId: cognitoClientId,
});
const verifyToken = (token: string) => verifier.verify(token);

const app = await buildServer({ db, itemsTableName, itemsQueueUrl, verifyToken });

// localhost 固定だと ALB のヘルスチェックが通らないので 0.0.0.0 で listen する
await app.listen({ host: '0.0.0.0', port: Number(process.env.PORT ?? 3000) });
```
